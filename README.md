# Login System
### A login system with account management and four built-in programs  

## Features
- Main Menu screen
- You can create and delete accounts with a limit of 7 accounts
- My Accounts screen to view the user accounts
- User can delete individual accounts from My Account Screen
- Reset Screen to delete all accounts
- Login System to access the Project Menu
- Project Menu with four programs
- Admin Account with a secret code ('1234') for testing
